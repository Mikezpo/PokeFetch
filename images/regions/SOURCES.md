# Region map artwork

The nine PNGs in this folder are the official illustrations linked from The Pokémon Company's regional-map poster article:

https://www.pokemon.com/us/news/adventure-from-kanto-to-paldea-with-the-pokemon-center-s-region-map-posters

Original image directory:

https://www.pokemon.com/static-assets/content-assets/cms2/img/misc/_tiles/pokemon-center/2023/03272023/inline/

Files: `kanto.png`, `johto.png`, `hoenn.png`, `sinnoh.png`, `unova.png`, `kalos.png`, `alola.png`, `galar.png`, `paldea.png`.
